## Default control changes

Keyboard: A/D or arrows move; Space jumps; S/Down crouches while held; E interacts; Ctrl/left mouse throws; Tab toggles inventory; brackets select an item; F uses the selected item; 1–9/numpad use slots directly; Esc pauses/backs out; R restarts after a result.

Controller: left stick/D-pad horizontal moves, south/A jumps, stick/D-pad down crouches, west/X interacts, right trigger throws, north/Y uses selected item, shoulders select items, Select/View toggles inventory and Start pauses/restarts after a result. Standard UI navigation uses stick/D-pad, south/A submit and east/B back. The controls screen shows device-appropriate effective names, not assumed Xbox labels for every controller.

## Learnings and known limits

- Do not validate a locked decorative door as if it were a usable teleport. The previous validation created misleading red Console errors.
- Do not put migration/media-coverage notes into the player's Settings screen. Keep notes in documentation unless a player decision requires them.
- UGUI Dropdown has no public IsExpanded property in the installed package. DropdownOpenState and a template/list lifecycle marker provide the needed state without reflection into private fields.
- Interactive rebinding must disable the action map, dispose its operation, preserve persistent binding IDs and prevent the captured button from also navigating the menu. Esc cancels; operations time out after ten seconds. Keyboard/mouse capture does not show a clickable cancel control because that click could itself become the new mouse binding.
- Large shell commands can exceed Windows process command-line limits (Win32 error 206). Prepare large source updates in bounded pieces before writing the final file.
- ffmpeg reported a trailing empty H.264 access-unit warning while decoding both the original and remuxed source (97 decoded frames from a stream listing 98 packets/frames). The metadata repair preserves those existing contents; it does not claim to repair unrelated source timestamps/trailing packets.
- Existing `Assets/Music/GameEffects/Pop.wav.meta` contains literal historic merge-conflict markers. The generated UI cues do not reuse that broken metadata. Resolving unrelated legacy audio metadata needs its own GUID/reference review.
